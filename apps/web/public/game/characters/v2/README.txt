ShieldQuest SG — original character pack
12 characters × 4 poses = 48 transparent 64×96 RGBA PNGs.

Folders:
- characters/female/F01..F06_{front,back,left,right}.png
- characters/male/M01..M06_{front,back,left,right}.png
- characters/mixed/ reserved for future character additions
- previews/character_lineup.png
- previews/direction_sheet.png
- previews/hdb_neighbourhood_mockup.png
- style-guide/pixel_style_guide.png
- working-files/shieldquest_12x4_64x96.png (4 columns × 12 rows, 64×96 cells)
- working-files/build_shieldquest_v2.js (reproducible source)
- manifest.json (IDs, pose order, sprite sheet row order)

All sprite feet align at y=91. Use nearest-neighbour texture filtering in Phaser.
The single PNG poses are the intended transparent in-game assets.
The preview backgrounds are presentation-only.

Characters are original pixel designs. The generated reference image was used for
overall warmth and wardrobe ideas, not copied or sliced into these sprites.
